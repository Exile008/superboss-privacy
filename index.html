超级BOSS - AI简历评估助手（适用BOSS直聘/猎聘）隐私政策

最后更新日期：2026年9月28日。适用于超级 BOSS 服务版本。

运营类型：个人开发者；运营主体：老肖；隐私与删除请求联系方式：微信 loopsay。

1. 信息收集

我们收集的信息仅限于：

  • 用户主动启动分析时处理的候选人简历文字、必要截图、评估规则及分析结果。
  • 评分阈值、自动动作开关、评估模板和筛选设置。
  • 随机安装标识、设备认证凭证、激活码兑换信息、额度和套餐有效期。
  • 用户主动点击“AI读简历”并完成当前版本上传授权后，读取并尝试发送当前招聘平台、页面中显示的招聘账号名与企业名。这些信息与安装设备关联，供服务端管理招聘账号与设备记录；不会在工作台初始化时自动上报。
  • 服务端记录调用类型、状态、时间及错误类型，用于计费、防滥用和故障处理；后台简历库还保存人选姓名、招聘平台来源和简历正文。

2. 信息使用

收集的信息仅用于：

  • 提供简历自动化评估服务
  • 生成分析报告和建议，以及用户选择的收藏和打招呼操作。
  • 核验试用与付费额度、管理设备访问、提供客服与异常补额。同一激活码不限设备数量，各设备共享额度；激活成功后取消剩余试用额度。
  • 将招聘平台账号及企业信息与设备记录关联，供运营方在后台识别设备使用情况。

3. 数据存储

BOSS 直聘与猎聘共用同一安装凭证、账户和额度；两站的筛选配置、分析结果及已分析记录分开保存。猎聘适配通过页面 DOM 读取已获授权访问的简历文字，不使用调试器截图，也不解锁受限附件或联系方式。

设置和分析结果存储在浏览器扩展存储中；部分设置可能通过 Chrome 同步。设备认证凭证仅用于访问超级 BOSS 服务，不是模型供应商 API 密钥。

分析时，简历文字或截图与评估规则经超级 BOSS 服务发送给已配置模型供应商。当前模型供应商：MiniMax M3 等系列模型。模型供应商对请求内容的处理与留存遵循其服务条款。

服务端简历库保存简历正文、人选姓名和平台来源；模型调用记录保存请求上下文与结果，相关正文按 90 天期限清理。为处理网络重试，模型响应另加密缓存 10 分钟，后台定期清理过期缓存。设备、授权及计费记录保留至账户删除或运营方适用的留存期限；生产反向代理的日志及备份保留期限：10 分钟。

4. 数据安全

插件与生产服务之间使用 HTTPS；本地开发版本使用回环地址 HTTP，不得直接对公网开放。管理员可配置可信内网的 HTTP 模型服务，该段传输不加密。模型密钥仅在服务端加密保存；新激活码同时保存校验哈希和加密副本，仅管理员可按需查看完整内容并记录访问日志。管理会话采用 HttpOnly Cookie 与请求校验。

除实现明确说明的用户功能、必要安全处理或法律要求外，不将候选人数据用于广告、出售、信用评估或训练通用模型。不得以“所有数据仅在本地”描述此服务版本。

5. 用户选择与删除

开始按钮旁会显示简历及招聘账号信息上传说明；点击“AI读简历”表示同意上传并开始分析，不再弹出额外确认窗口。仅打开工作台不会上传简历、招聘账号名或企业名；每次开始分析时会在有效授权下尝试关联招聘账号信息。停止分析可阻止后续简历处理，但不能撤回已经发送的请求或已经开始的账号信息关联。查询账户和激活码验证无需同意简历上传，传输安装凭据和激活信息。可通过“清空结果”删除本机分析结果，或卸载扩展删除本机扩展数据。服务器账户、设备、招聘账号信息、额度及调用记录的删除请联系运营方；管理员可停用账户并执行数据删除。

6. 第三方访问与使用边界

用户应确保具备处理候选人个人信息的合法权限。AI 输出可能不准确，应由招聘人员复核，不应作为唯一录用依据。使用者仍须遵守 BOSS 直聘及其他相关平台的规则。
